# Feature: Temporärer Gameplay-Buff oder Status-Effekt

## Ziel

Der Spieler kann einen temporären Effekt erhalten, der das Gameplay für kurze Zeit verändert und danach wieder zurückgesetzt wird.

## Beschreibung

Im Level gibt es mindestens einen aufnehmbaren Buff oder Status-Effekt. Beispiele sind schnelleres Laufen, höheres Springen, Schild, Schadensreduktion, schnellere Feuerrate oder kurzzeitige Unverwundbarkeit. Das Feature soll einen klaren Start, eine aktive Dauer und ein definiertes Ende haben.

## Akzeptanzkriterien

- [ ] Der Buff kann durch eine Spieleraktion oder ein Pickup aktiviert werden.
- [ ] Der Buff hat eine begrenzte Dauer oder eine klar definierte Abbruchbedingung.
- [ ] Der aktive Effekt verändert ein bestehendes Gameplay-System spürbar.
- [ ] Der Spieler erhält Feedback beim Aktivieren und beim Ende des Effekts.
- [ ] Nach Ablauf wird der ursprüngliche Zustand verlässlich wiederhergestellt.

## Definition of Done

- [ ] Das Feauture ist vollständig implementiert.
- [ ] Alle Akzeptanzkriterien sind erfüllt.
- [ ] Das Feature ist vollständig getestet (Edit Mode und/oder Play Mode) und die Tests sind erfolgreich.
